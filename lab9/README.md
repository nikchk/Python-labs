# Завдання: Аналіз даних IT-працівників та проєктів (Pandas)

## Умова
Аналіз набору даних у форматі CSV, що містить детальну інформацію про IT-фахівців (ім'я, прізвище, дата народження, стаж, посада, рівень, відділ, зарплата, премії, поточний і попередні проєкти, стек технологій) та проєкти компанії (назва, дати контракту, бюджет, необхідні технології та кількість спеціалістів).

За допомогою бібліотеки **Pandas** та середовища **Jupyter Notebook** необхідно визначити:
1. Кількість працівників працює на кожному з проєктів.
2. Розподіл кількості працівників за рівнями по кожному з проєктів.
3. Сумарні зарплатні виплати по кожному з проєктів за один місяць.
4. Прибутки компанії по кожному з проєктів за один місяць (з візуалізацією через стовпчикові або інші діаграми).
5. Список проєктів, де прибутковість більша, ніж 20% від бюджету.
6. Список працівників, які знають Python та їх зарплата перевищує 3000$.
7. Сумарний прибуток компанії за місяць, у випадку, якщо зарплата сеніой-спеціалістів буде більшою на 20%.
8. Віковий розподіл працівників за кількома категоріями (наприклад: до 30, 30-40, 40-50, >50%) з побудовою кругової діаграми.
9. График залежності зарплати від стажу на основі даних про працівників.
10. Технологію, якою володіє найбільша кількість працівників.
