# Завдання 3: Трансформація площини в криву

## Умова
Нехай в декартових координатах параметрично задано деяку криву L: $x=x(t), y=y(t), 0<t<T$. Нехай задано деяку періодичну функцію $g(s)$ з достатньо малою амплітудою. 

Написати програму, яка на основі заданих з клавіатури функцій малює криву, яка утворюється з графіка функції $g(s)$ в декартових координатах шляхом трансформації площини, при якій вісь $s$ переходить в криву L (наприклад, якщо крива L – коло, а $g(s) = A \sin(ks)$).
