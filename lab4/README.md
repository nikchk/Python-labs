# Завдання 4: Метод Монте-Карло для обчислення площі

## Умова
Нехай з клавіатури задано відрізок $[a,b]$ та функції $f(x)$, $g(x)$. 

Написати програму, що дає змогу методом Монте-Карло обчислювати площу фігури, що обмежена графіками заданих функцій і прямими $x=a$ та $x=b$. Візуалізувати на одній координатній площині графіки цих функцій, обмежуючі прямі (включно з додатковими горизонтальними прямими) та використані в обчисленнях псевдовипадкові точки.
