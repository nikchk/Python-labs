# Завдання 2: Обробка транспортних маршрутів

## Умова
Створити тип «транспортний маршрут» (початкова станція, кінцева станція, к-сть зупинок, протяжність маршруту в км). 
Дані про маршрути задаються у файлі. 

Необхідно реалізувати такі можливості:
1. Створити список маршрутів.
2. Посортувати його за протяжністю.
3. Вивести к-сть маршрутів, для яких середня довжина між зупинками менша за X.
4. Створити список маршрутів, які починаються в станції Х.
5. Вивести маршрути з максимальною к-стю зупинок.
