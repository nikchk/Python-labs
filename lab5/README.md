# Завдання 5: Клас Matrix на базі NumPy

## Умова
Написати консольну програму, що реалізує простий текстовий інтерфейс для виконання різних операцій з матрицями. 

У програмі реалізувати клас-обгортку `Matrix`, що інкапсулює елементи матриці та внутрішньо реалізує всі операції із використанням **NumPy**:
- Введення матриць з клавіатури.
- Операції додавання, віднімання, множення, транспонування.
- Знаходження оберненої матриці та розв’язування систем лінійних рівнянь.
- Знаходження власних значень, векторів та норми матриці.
- Реалізувати інтерфейс ітератора для послідовного порядкового обходу всіх елементів матриці.
- Реалізувати функцію-генератор для отримання ітератора, що здійснює обхід елементів матриці по спіралі.
